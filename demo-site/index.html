Site fictício para testes. Use apenas contas e senhas inventadas.

Banco Exemplo (demonstração)

  • Entrar — login convencional (usuário + senha).
  • Criar conta — cadastro com senha e confirmação (gerar e salvar).
  • Página com campos ocultos — a senha não pode ir para campos escondidos.
  • Login que aparece depois — formulário montado após 2 segundos.

Para testar domínio incompatível, abra a mesma página por http://127.0.0.1:8080/login.html: o endereço é outro, então a conta salva para localhost não pode ser usada.
